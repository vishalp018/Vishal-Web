# Vishal Web — Portfolio Website

My personal portfolio website showcasing my education, work experience, projects, and a feedback section.

🔗 **Live Demo:** [vishalpal18.vercel.app](https://vishalpal18.vercel.app/)

## Tech Stack

- React.js
- Node.js & Express.js
- MongoDB
- Firebase

## Features

- 🎓 Education section
- 💼 Work experience section
- 🚀 Projects showcase
- 💬 Feedback section

## Getting Started

```bash
git clone https://github.com/vishalp018/Vishal-Web.git
cd Vishal-Web
npm install
npm run dev
```
